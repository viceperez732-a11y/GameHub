# 🎮 Game Hub — Frontend

SPA académica para explorar y simular la renta de videojuegos por 1 mes.

## Tecnologías
- React
- Vite
- JavaScript
- Tailwind CSS
- React Router

## Vistas incluidas
- Inicio
- Registrarse
- Catálogo

## Interactividad
- Formulario de registro con `useState`
- Mostrar/ocultar contraseña
- Búsqueda en tiempo real
- Filtros por género
- Filtro de precio
- Ordenamiento
- Favoritos
- Modal de detalles
- Modal de confirmación de renta

## Ejecutar

```bash
npm install
npm run dev
```

## Importante
Las imágenes y los datos incluidos son de demostración. La renta y el registro son simulaciones de frontend; no existe backend ni procesamiento real de pagos.
